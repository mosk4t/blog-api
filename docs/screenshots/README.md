# Screenshots to take before submission

Please start the local server after `python manage.py migrate` and `python manage.py seed`.
Log in using your own superuser and capture REAL screenshots:

1. `dashboard.png` — `/admin/`: cards, chart, author table, progress bars.
2. `posts-filters.png` — `/admin/blog/post/` with filter panel open.
3. `post-edit.png` — open an individual post and show edit tabs.
4. `users-list.png` — `/admin/auths/user/` with labels visible.

Do not submit placeholders or fake interface screenshots. These files must be added by you
once Django is running on your computer.
